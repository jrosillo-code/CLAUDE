# Reference design systems

Copied from https://github.com/VoltAgent/awesome-design-md (commit `8147538`), a curated
collection of DESIGN.md files extracted from public websites. Per that repository's
license note, the files are provided as is, represent publicly visible CSS values, and
carry no claim over any site's visual identity.

These are inspiration for the company's own `../../DESIGN.md`, never targets to copy.
Why each one is here:

| File | What to borrow | What not to borrow |
|---|---|---|
| `wired.DESIGN.md` | Paper-white editorial density, serif display over a grotesque, ink-blue links | Broadsheet column density; we are single column |
| `notion.DESIGN.md` | Warm minimalism, serif headings, soft surfaces, restrained radius | Pastel card tints and illustration; we show real UI |
| `linear.DESIGN.md` | Precision and restraint for app screens, hairline hierarchy, tabular figures | Dark canvas and purple accent |
| `stripe.DESIGN.md` | Trust-focused fintech clarity, weight-300 elegance, numbers as proof | Signature gradients |

To refresh or add one: `git clone --depth 1 https://github.com/VoltAgent/awesome-design-md`
and copy `design-md/<site>/DESIGN.md` here with the site name as prefix.
