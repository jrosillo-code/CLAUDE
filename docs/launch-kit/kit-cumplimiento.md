# Kit de cumplimiento

*Ships with every build. In Europe this is the pitch, not the overhead: "no es un chatbot
cualquiera, es un flujo auditable diseñado para empresas europeas".*

1. **Aviso de IA.** Toda comunicación generada o asistida por IA lo indica (Reglamento
   Europeo de IA, artículo 50, en vigor desde el 2 de agosto de 2026). Texto estándar en
   pie de email y mensaje de WhatsApp.
2. **Revisión humana.** Ningún envío externo ni escritura definitiva en el sistema de
   gestión sin aprobación de una persona. La cola de aprobación es parte del producto.
3. **Registro de actividad.** Cada documento recibido, cada extracción, cada validación,
   cada borrador y cada aprobación quedan registrados con fecha, usuario y versión del
   modelo. Exportable.
4. **Trazabilidad.** Cada dato extraído enlaza con el documento y la página de origen. La
   IA nunca inventa un dato: si no está en el documento, se marca como ausente.
5. **Datos.** Contrato de encargo del tratamiento (RGPD). Datos de salud y de terceros
   tratados dentro de la UE. Retención definida por el cliente. Sin uso de datos del
   cliente para entrenar nada.
6. **Facturación.** Si el flujo emite facturas, se integra un motor certificado Verifactu;
   nunca se implementa el registro, el hash o el envío a la AEAT por cuenta propia
   (responsabilidad de "productor" y declaración responsable).
7. **Coste y límites.** Presupuesto de tokens por flujo con alerta, para que el cliente
   sepa cuánto cuesta cada mes antes de que llegue la factura.
