# Launch kit

Materials for the first 30 days of `../plan-2026-09.md`. Client-facing documents are in
Spanish because the buyers are Spanish; internal templates carry English notes.

| File | Use |
|---|---|
| `oferta.md` | One-page offer with the three tiers. Basis for the website and for proposals. |
| `guia-entrevista.md` | The discovery interview, identical for insurance brokerages and accounting firms, with a scoring sheet for the week-four gate. |
| `piloto-rosillo-hermanos.md` | Outline of the written pilot agreement with the family brokerage. |
| `inventario-flujos.md` | Week-one workflow inventory template: what to count inside a firm before choosing the pilot workflow. |
| `prospectos.md` | How to assemble the first 100 prospects on each track, and the outreach sequence. |
| `kit-cumplimiento.md` | The compliance kit every build ships with: disclosure, review step, logs, data policy. |

Rules that apply to everything here: sell scope, never hours; 50 percent up front; no build
without a buyer; the family pilot discovers the workflow and is not market evidence; every
number quoted to a client is re-verified first.
